# 风格参考｜真实帖子原文

> **这 5 篇是别人发布的真实帖子，不是本人写的。** 它们是「纽约中古店探店 / 种草」这个品类的写法参照，学的是这个品类怎么开口、怎么放信息、怎么收尾。
>
> **怎么用：写之前读，吸收这几篇的说话方式去模仿，不是抄结构、不是套模板。** 注意怎么开头（几乎都不铺垫，第一句就交代来路或直接给店名）、具体信息怎么塞（品牌 + 单品 + 价格 + 成色，一次给足）、emoji 怎么当分隔符用、地址和营业时间怎么单独成行、结尾怎么从「这家店」拉回到「我这个人」。
>
> 每篇开头标了类型和数据表现，挑和当前帖子最接近的那篇做主要参照。

**要避开的点**

## 共性拆解（写之前先过一遍）

**开头**：五篇没有一篇铺垫。要么借人（「被朋友推荐了好多次」「听身边朋友一直推荐」），要么自贬（「咱也不是啥探店博主」），要么立资历（「也算是逛遍纽约中古了」），要么直接甩信息（「省流先上店铺」）。绝不写「今天给大家分享一家……」。

**中段的硬通货**：品牌 + 具体单品 + 价格 + 成色，四样缺一样都会掉到帖子5 的水平。价格给数字（300、200-400、五分之一），不写「性价比高」。年份、房间号、开门时间这类硬信息越多，收藏越高。

**私人感怎么加**：不是加感叹号，是加一个只有你会说的比较。「比我年纪都大耶」「不是臭臭的那种」「已经开始期待秋天了」——都是把物品换算成自己的生活。

**标点和排版**：短句一句一行；用空格断句；emoji 当分隔符和语气标记（🚪店名、🕰时间、📍地址、🔍搜索、💵价格）；「-」当分隔线；括号可以不闭合。不用 markdown 标题、不用 bullet。

**结尾**：从店拉回到人。「越来越喜欢逛纽约这些藏在小巷子里的小店」「真的很喜欢纽约街头的一些小店」「下次这么好的店铺我可要偷偷藏着了」。不写「希望对你有帮助」「快去打卡」。

**信息块位置**：地址、营业时间、预约方式放正文最后、hashtag 之前，每条单独成行、带 emoji 起头。

**hashtag**：8-10 个，大词 + 长尾混着来（#纽约中古 是大词，#纽约vintage店 #留学生探店 #有点爱购物且有点品位 是长尾）。帖子5 只放 3 个泛词是它数据差的原因之一。
